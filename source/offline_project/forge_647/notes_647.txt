The master Forge carries the full Carpe Diem 1058, not its committee demo, with the master edition of Ingenium and Inkwell 7.52;
only the Forge's demonstration carries a demo. The licence is version 3, the owner's own key is carried, and a permission signed
with it is checked in Settings, About. A page brought in from outside (Files, a backup, a chat's files, GitHub) is shown in the
preview apart from the Forge: it runs, but cannot read what the Forge keeps, reach the window around it, or have the Forge save a
file for it. The owner's own apps (those the Forge carries, builds baked from them, and any the owner marks with "This is my own
app", pressed twice) keep the Forge's origin and its live edits. The diary and the command chat draw outside text through a strict
cleaner, a zip brought in is unpacked only to the size it declares, and the five apps the Forge carries in its page (Tabula,
Abacus, Imago, Scriba, Fontes) take in markup only through that cleaner. On Windows 10 the side menu and the side keys show
Microsoft's flat emoji drawings, as on Windows 11, without the heavy black outline. A search in a large file opened part by part
selects the word it found again. On Windows a page whose process stops is loaded again by itself; on a Mac, only the Forge's own
page may call the program, and a document to print is opened only as a PDF, a web page, plain text or a picture. A file saved
with no dialog never replaces another. The Fire tablet app is signed with a new key, handed over from the old one, which was in a
public repository; its stored data stays on the tablet; the microphone is given only to the Forge's own page, links to other
addresses open in the browser, no page is given the tablet's files, and the clipboard is read only for the Forge's own page. On
the iPhone and iPad only the Forge's own page is heard, and the icon stands on white.
