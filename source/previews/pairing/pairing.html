Its models, the apps it sends you, runs and logs: all sealed with a key only these two devices hold.

What changes

  • Each device makes a key of its own when it pairs; the two agree on a shared key without ever sending it.
  • The four words prove that no one in between swapped the keys. You compare them once per device.
  • Every message is sealed (AES-GCM). Anyone else on the Wi-Fi sees only noise, and the code is no longer sent.
  • An app you send waits on the computer sealed for that device alone.

What stays as it is

  • Finding your computers, the code typed once, Remove beside each device.
  • A device paired before 7.37 keeps working with the code, marked Pair once more, until you pair it again.
  • An app you serve for the Home Screen stays readable to browsers on your home network while you serve it: Safari has to read it.

Still to check

  • Whether the iPhone and iPad app can seal at all: its page runs from a private address, and I have not yet confirmed that iOS allows the sealing there. If it does not, Settings, Security will say so for those devices.
  • Settings, Security then shows Sealed between your devices as On.
